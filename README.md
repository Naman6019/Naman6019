## 🧩 What I'm Working On



### 🚀 FundersAI

**FundersAI** is an AI-orchestrated financial research platform for Indian markets, built to help retail investors compare mutual funds, analyze market data, and generate research-backed insights through AI-powered workflows.

The platform combines **quantitative metrics, NAV history, news sentiment, fund comparisons, and automated data pipelines** into a clean research dashboard. It uses a **Supabase-first architecture** for fast reads, **FastAPI** for backend services, and **Next.js** for the frontend.

#### Core Highlights

- 🤖 **AI Chat & Intent Routing**  
  Routes user queries into specialized workflows for quant research, news analysis, screeners, and comparisons.

- 📊 **Mutual Fund Comparison Canvas**  
  Compares funds using NAV history, returns, alpha, beta, Sharpe ratio, and AI-generated insights.

- ⚙️ **Automated Data Pipelines**  
  Uses GitHub Actions to sync stock data, mutual fund data, NAV history, and AMC disclosures.

- 🔒 **Quota-Safe Architecture**  
  Serves query-critical data from Supabase tables while storing raw and archival data in Cloudflare R2.

- 💼 **Auth & Subscriptions**  
  Includes Supabase Auth with Email/Google login and a Razorpay-backed subscription foundation.

- 🛠️ **Admin Dashboard**  
  Tracks AI usage, parser diagnostics, data coverage, user activity, and system health.

#### Tech Stack

`Next.js` · `React` · `TypeScript` · `Tailwind CSS` · `FastAPI` · `Python` · `Supabase` · `PostgreSQL` · `Cloudflare R2` · `GitHub Actions` · `Vercel` · `Render`
